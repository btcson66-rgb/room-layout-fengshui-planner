# 第一次租屋房間怎麼規劃？最貴的錯誤發生在看房那天

第一次租屋的人通常把心力放在「搬進去之後怎麼佈置」，但真正決定房間好不好住的那幾件事——門窗位置、插座位置、樓高、隔間——**在你簽約的那一刻就全部定案了**，而且之後一件都改不掉。

所以這篇分成三段：看房、入住前、住進去之後。順序不能顛倒。

## 第一段：看房那天要量的六個數字、要問的四件事

**要量的（帶捲尺，不要目測）：**

1. **房間淨長與淨寬**——扣掉樑柱突出的部分，量地板不量牆面中段
2. **房門淨寬**——門片打開後的實際通過寬度。這決定家具能不能進來
3. **窗台高度**——地板到窗框下緣。決定哪些家具能貼窗放
4. **樓高**——決定能不能用高架床、架高地板這類垂直方案
5. **插座位置與數量**——連高度一起記，這是最常被漏掉的一項
6. **搬運路徑最窄處**——電梯內部、樓梯轉角、走廊轉彎

六個數字記在手機裡，之後每一次買家具都用得到。

**要問的：**

- **可以做到哪一級？** 具體問「可移除式掛勾可以嗎」「窗簾軌道可以裝嗎」，比籠統地問「可以裝東西嗎」容易得到明確答案。分級方式見[租屋房間配置怎麼規劃](/zh/blog/rental-room-layout-planning/)。
- **既有家具能不能移走或處理？** 附家具的房間常有你用不到的大件，先問清楚能不能收起來。
- **潮濕與漏水的歷史。** 看牆角、天花板、窗框周圍有沒有水痕。
- **管理費、電費計價方式、網路。** 這些不影響配置，但影響你負擔得起多少其他東西。

**當場拍照。** 牆面、地板、門窗、既有損壞全部拍下來——這是退租時你唯一的依據。

## 第二段：入住前兩週買什麼，延後買什麼

新手最常見的失敗是「搬家前一週把所有東西買齊」。結果是買了不需要的、尺寸錯的、以及風格不搭的。

**先買（沒有會過不下去的）：**
- **床墊**——這是唯一該花錢的一項，直接影響每天的睡眠
- **窗簾**——沒有窗簾第一晚就會後悔
- **基本照明**——房東附的主燈通常不夠
- **一組可堆疊的收納箱**——過渡期先有地方放東西

**延後兩到四週再買：**
- **衣櫃、書桌、層架**——住過之後才知道實際需要多大、放哪裡
- **地毯、裝飾品**——這些是最後才做的事
- **任何「看起來很適合」的收納家具**——先搞清楚自己實際有多少東西

**能不買就不買的：**
- **成套的臥室家具組**——套組尺寸是為標準房間設計的，租屋分開挑更合適
- **訂製尺寸的任何東西**——只適用當下這個房間，下一個幾乎一定不合
- **整體式（不可拆裝）的大家具**——搬第二次通常就報廢

判斷原則：**買之前問「這個東西我會不會為了帶走它而多花一趟搬運費」**。答案是「不會」的話，就買便宜的、或先不買。

## 第三段：住進去之後，依這個順序排配置

配置的邏輯跟自有住宅一樣，只是選項變少：

1. **先扣走道**——主動線 55–60 公分，這部分不參與分配（見[房間走道寬度指南](/zh/blog/room-circulation-width-guide/)）
2. **床先定**——選沒有門、沒有窗、不在門正對線上的那面牆
3. **衣櫃吃掉最暗最深的牆**——它不需要採光
4. **書桌搶剩下的窗邊位置**——讓窗在側面，不要正對也不要背對
5. **收納往上長**——地板永遠不夠，垂直發展，做法見[租屋免鑽孔收納](/zh/blog/renter-no-drill-storage/)

搬家具之前先用[房間佈局規劃工具](/zh/room-layout-planner/)排一次，租屋專用的起點見[租屋房間配置工具](/zh/rental-room-layout/)。實際搬三次不如先畫十分鐘。

## 一個人住的三個生活動線，比家具位置更該先想

配置排完之後，用三條每天都會走的路線驗證一次。這三條走不順的房間，
不管家具多好看都住不舒服。

**起床動線**：床 → 開燈 → 拿衣服 → 出房門。這條路上不應該要繞過任何家具，
而且早上意識不清時走得過。床頭到燈的開關（或床頭燈）要伸手可及。

**回家動線**：進門 → 放包包鑰匙 → 脫外套 → 洗手。門口附近要有一個
「放東西的定點」——沒有的話，包包和鑰匙就會每天出現在不同的地方。
一個小掛勾加一個淺盤就夠，這是投報率最高的一平方公尺。

**夜間動線**：床 → 房門（去廁所）。這條路要在黑暗中走得過，
所以路徑上不能有電線、不能有低矮的家具腳、也不該有需要繞行的東西。
一盞感應小夜燈解決大部分問題。

三條路線各走一次，卡住的地方就是需要調整的地方——這比對著平面圖想像有用得多。

## 新手最常後悔的六件事

1. **看房沒帶捲尺。** 後果是家具買回來放不下，或根本進不了門。
2. **床墊買便宜的。** 這是唯一每天用八小時的東西，也是最不該省的一項。
3. **一次買齊所有家具。** 住過兩週之後你對需求的判斷會完全不同。
4. **買了整體式大衣櫃。** 下次搬家時你會認真考慮把它丟掉。
5. **沒有在入住第一天拍照。** 退租時被扣押金卻拿不出證據。
6. **把配置的問題當成收納的問題。** 買了一堆收納盒，但真正的問題是走道太窄、床位不對。

## 常見問題

**Q：預算有限，家具該從哪裡開始買？**
床墊 → 窗簾 → 照明 → 收納 → 書桌 → 衣櫃。前三項先到位，其餘可以用箱子與臨時方案撐兩三週，等你更了解這個房間。

**Q：房東附的家具很醜、很佔空間，怎麼辦？**
先問能不能移走或收到別的地方。不行的話，用布蓋起來、或讓它變成分區用的家具背面（見分區的做法）。硬要跟它共存又每天覺得礙眼，是可以避免的。

**Q：第一次租屋要不要買床架，還是床墊直接放地上？**
建議買床架或至少用架高的床墊架。台灣濕度高，床墊直接貼地非常容易在底面長霉，而且灰塵集中在地面附近。

一句話：第一次租屋最重要的裝備不是收納盒，是看房那天口袋裡的捲尺。

## 小結

房間規劃沒有唯一正確答案。請先用實際尺寸建立配置，再依照睡眠、動線、採光、收納與安全需求微調；風水內容請作為民俗文化與空間舒適度參考，不保證任何結果。
