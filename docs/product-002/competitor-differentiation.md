# PRODUCT-002 Competitor differentiation gate

本比較是 Phase 1 的定位檢查，不是正式銷售宣稱。

| Use case | Free interactive planner | Static PDF / marketplace guide | PRODUCT-002 intended extra value | Gate |
| --- | --- | --- | --- | --- |
| 10×10 Queen + desk | 可自行拖家具，但使用者從空白開始 | 多半提供幾張範例圖與 worksheet | 先用尺寸 matcher 篩掉不合房間的 layout，再顯示 score breakdown、trade-off、clearance class 與 Planner import | Must verify after UI |
| 240×300 student room | 常有 generic furniture presets | 靜態建議需自己換算尺寸 | 將 study-first、sleep-first、storage-first 以同一 schema 比較，而非只換配色 | Must verify after UI |
| 3048×3658 queen room | 可畫出家具 | 可能提供 10×12 PDF 但沒有個人 fit reason | Queen + desk、Queen + wardrobe、Full + desk + wardrobe 皆有可追溯 archetype 與取捨 | Must verify after UI |
| Micro studio | 能畫家具，但不一定檢查 zone completeness | 內容 bundle 多半沒有 deterministic fit | sleep/work/living/dining/storage zones、entry route 與 privacy strategy 是明確欄位 | Must verify after studio rules |
| Existing Planner workflow | 需要重新輸入 furniture | 不能匯入既有結構化 layout | Open in Planner 傳 room、furniture、coordinates，避免重新測量／重畫 | Must verify after integration |

Positioning fails if the released product cannot demonstrate at least matcher reason, multiple strategies, clearance classification, explicit trade-offs, compare, and Planner import beyond a static PDF or a blank canvas.
