## Brief A — 床頭靠牆 cluster

- target market：台灣／繁中
- language：zh-TW
- primary intent：床頭一定要靠牆嗎？床頭靠窗、懸空或床側靠牆時，使用者想知道怎麼判斷
- secondary intents：床頭靠窗、床頭不靠牆化解、床左側靠牆
- user situation：小房間或租屋族無法同時保留兩側走道，正在做床位取捨
- existing URL collision：`/zh/blog/bed-head-against-wall/` 是 canonical owner；`/zh/blog/bedroom-bed-left-wall-access-feng-shui/` 只處理床側靠牆的日常使用，不合併
- SERP gap：結果常把「床頭靠牆」當成絕對規則，較少把支撐、窗扇／窗簾操作、清潔與門窗動線放在同一個判斷流程
- unique value：三問決策表；把民俗「有靠」拆成可觀察的支撐、操作與維護條件；保留原有房間案例、工具與來源
- required diagrams：不新增 UI；沿用現有正文表格與工具連結
- required calculations：不新增神奇距離；依實際床架、門窗、家具外框判斷
- required examples：既有床頭靠牆／靠窗／床側靠牆情境，維持不同取捨
- internal links：既有 room planner、bed-desk-wardrobe、room circulation、furniture measurement links
- sources：既有正文的 EPA／CPSC／NFPA 等來源；本輪新增表格未新增外部統計或安全法規宣稱
- title：床頭一定要靠牆嗎？床頭靠窗、懸空與床側靠牆的判斷
- H1：床頭一定要靠牆嗎？先確認支撐、門窗與實際動線
- snippet answer：不一定要靠牆，但頭部後方要有穩固支撐，且不能製造門片、走道、濕氣、光線或噪音問題。
- CTA：用房間配置工具比較不同床向，再用家具尺寸適配檢查核對外框與走道
- limitations：風水只作民俗文化與空間舒適度參考，不保證健康、財運、感情或其他結果

## Brief B — 床對門 cluster

- target market：台灣／繁中
- language：zh-TW
- primary intent：床對門怎麼辦，應不應該移床或加化解物
- secondary intents：床頭對門、床尾對門、床頭對門化解
- user situation：住戶看到床與門有視線直線，擔心民俗說法，但不想因誤判讓出口或走道變差
- existing URL collision：`/zh/blog/bed-facing-door-feng-shui/` 是 canonical owner；不拆成床頭／床尾／床側三個 permutation URLs
- SERP gap：多數結果直接給「禁忌／化解」結論，較少先分床頭、床尾、床側，再檢查門片弧線、出口、光聲與隱私
- unique value：15 分鐘可重現檢查；門片／出口／光聲／日常四張便條；不把屏風當預設答案
- required diagrams：沿用現有正文流程與 tool CTA，不重做 shared shell
- required calculations：以現場門片與家具外框為準，不宣稱單一法定或神奇距離
- required examples：既有 280 × 320 公分案例與三種床門關係
- internal links：bed-door-fix-selector、room-layout-planner、feng-shui-bedroom-checker、mirror-facing-bed
- sources：既有正文的 USFA／CDC／NIOSH／CPSC 來源
- title：床對門怎麼辦？先分床頭、床尾與床側再決定化解
- H1：床對門怎麼辦？先分清床頭、床尾與床側
- snippet answer：床對門不必一律移床；先分辨床頭、床尾或床側，再檢查門片、出口、光線、聲音與隱私。
- CTA：用床對門化解方案選擇器比較平移、轉向與視線緩衝
- limitations：風水只作民俗文化與空間舒適度參考，不保證任何結果

## Brief C — 書桌對門 cluster

- target market：台灣／繁中
- language：zh-TW
- primary intent：書桌正對、背對或斜對門時，怎麼判斷是否真的影響使用
- secondary intents：書桌對門好嗎、書桌背對門、書桌風水
- user situation：小房間需要把桌子放在門附近，分不清是門口動線問題還是視線／聲音／反光問題
- existing URL collision：`/zh/blog/desk-facing-door-layout/` 是 canonical owner；不為正對／背對／斜對門拆頁
- SERP gap：常見頁面把座向直接等同好壞，沒有把椅子拉出、門片掃掠、反光與 3 天紀錄放在同一個 decision model
- unique value：3 天分心紀錄；60–75 公分門口走路帶檢查；正對／背對／側向取捨表
- required diagrams：沿用既有表格與工具 CTA，不另造 UI
- required calculations：檢查桌面與椅子使用範圍是否侵入門口動線，不把 60–75 公分宣稱為通用法規
- required examples：既有背對門、正對門、共用空間三種情境
- internal links：desk-door-fix-check、bed-desk-wardrobe、small-bedroom、room-circulation
- sources：本輪未加入新的安全或統計宣稱；既有內容維持既有來源與限制
- title：書桌對門好嗎？正對、背對與斜對門的 3 天判斷
- H1：書桌對門好嗎？先分正對、背對與門口動線
- snippet answer：書桌對門不一定要搬；先量桌面與拉開椅子是否占到門口走路帶，再用 3 天紀錄分辨視線、聲音或反光。
- CTA：用書桌對門化解檢查器估算可行側移／轉向，再回到房間配置工具複核
- limitations：風水只作民俗文化與空間舒適度參考，不保證專注力、成績或工作結果
