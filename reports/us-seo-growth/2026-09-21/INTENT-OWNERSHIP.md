# RoomFeng US SEO Growth 002 — Intent Ownership

The implementation keeps one primary owner for each query family. Related links are contextual handoffs, not a reason to make every page answer every query.

| Page | Primary ownership | Explicit boundary |
|---|---|---|
| `/en/furniture-fit-checker/` | Furniture fit, furniture fit checker, room fit, everyday room clearance | Checks the item inside the destination room and its requested operating clearance. It does not model a full delivery route, stair turns, elevator geometry, or hallway-corner rotation. |
| `/en/furniture-fit-calculator/` | Furniture footprint plus requested-clearance math | US Expansion 001 page. Not modified in this task. |
| `/en/moving-furniture-size-check/` | Furniture delivery measurement, door/hallway/stair/elevator route, apartment delivery route | The authoritative ordered route guide. It does not claim that a diagonal or rectangle check proves a 3D maneuver. |
| `/en/couch-fit-through-door-calculator/` | Couch/sofa doorway opening screening | Remains a focused one-doorway tool; stairs, elevators, turns, and full delivery route belong to Moving Furniture Size Check. |
| `/en/small-bedroom-layout-planner/` | General small-bedroom layout planning and room-size workflow | Links to exact-size owners and hands off the specific bed + desk + wardrobe intent. It does not claim every listed furniture set automatically fits. |
| `/en/bed-desk-wardrobe-layout/` | Small-bedroom layout with bed, desk, and wardrobe; measured three-piece scenarios | Focused on the exact set and measured screening examples, not a generic answer to every small bedroom query. |
| `/en/studio-apartment-layout/` | Generic studio apartment zoning and layout pillar | Links to existing 300/350/400/450/500 sq ft owners. It does not create intermediate area permutations or equate listing area with clear open floor. |
| Existing 300/350/400/450/500 sq ft pages | Exact studio-size supporting scenarios | Existing owners remain unchanged and support the studio pillar. |

## Link direction used in this task

- Furniture Fit Checker → Moving Furniture Size Check for the full delivery route.
- Moving Furniture Size Check → Furniture Fit Calculator for room footprint, Furniture Fit Checker for everyday clearance, and Couch Fit Through Door Calculator for one-doorway screening.
- Small Bedroom Layout Planner → six existing exact-size bedroom owners and Bed Desk Wardrobe Layout for the specific three-piece scenario.
- Bed Desk Wardrobe Layout → Room Layout Planner for measured planning and Small Bedroom Layout Planner for the general workflow.
- Studio Apartment Layout → existing 300/350/400/450/500 sq ft owners and the dedicated 400 sq ft page for deeper measured layouts.
